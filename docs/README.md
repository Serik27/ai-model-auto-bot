# AI Model Studio Telegram Bot 📸🤖

Телеграм-бот для генерації високоякісних фото віртуальної AI-моделі дівчини за допомогою **Google Gemini (Nano Banana / Flash Image)** та **aiogram 3**.

---

## 🌟 Ключові можливості

1. **Збереження образу AI-моделі (Face & Body Consistency)**:
   - Збереження референсу **обличчя** (Face) для ідентичності рис, очей, носа, посмішки та волосся.
   - Збереження референсу **фігури / тіла** (Body) для фіксації пропорцій, зросту та силуету.

2. **Генерація за 3 референсами (Поза + Одяг + Фон)**:
   - **Поза (Pose)**: точне перенесення позиції тіла, жестикуляції та ракурсу.
   - **Одяг (Outfit)**: одягання моделі в обраний лук (сукня, костюм, купальник) з природною посадкою по фігурі.
   - **Фон (Background)**: органічне розміщення моделі на будь-якій локації (пляж, студія, місто) з адаптацією освітлення та тіней.

3. **Вбудована черга з урахуванням безкоштовного ліміту (2 RPM)**:
   - Безкоштовний план Gemini API має ліміт **2 запити на хвилину**.
   - Асинхронний черговий воркер (`GenerationQueueWorker`) витримує безпечну паузу **~32 секунди** між генераціями.
   - Автоматичний повтор (exponential backoff) при отриманні помилки `429 (Resource Exhausted)`.
   - Інформування користувача про позицію в черзі та орієнтовний час очікування в реальному часі.

4. **Пакетний копірайтинг (Instagram/Threads + X/Twitter англійською)**:
   - Щоб не витрачати окремі запити API на кожне фото, описи та хештеги створюються **пачкою за 1 запит** до текстової моделі Gemini (`gemini-3.8-flash`).
   - Для кожного фото створюється:
     - **Instagram / Threads**: естетичний lifestyle-опис від першої особи, емодзі, гачок та 15-20 трендових хештегів.
     - **X (Twitter)**: влучний пост до 280 символів з топовими хештегами.

## 🚀 Встановлення та запуск

### 1. Клонування або перехід у папку проекту
```powershell
cd "c:\Users\omnik\OneDrive\Рабочий стол\Ai_model_auto"
```

### 2. Встановлення залежностей
```powershell
pip install -r requirements.txt
```

### 3. Отримання ключів
- **Telegram Bot Token**:
  1. Відкрийте Telegram і напишіть боту [@BotFather](https://t.me/BotFather).
  2. Відправте команду `/newbot`, оберіть назву та юзернейм.
  3. Скопіюйте наданий `API Token`.

- **Google Gemini API Key**:
  1. Перейдіть на [Google AI Studio](https://aistudio.google.com/).
  2. Натисніть **"Get API key"** -> **"Create API key"**.
  3. Скопіюйте ваш безкоштовний ключ.

### 4. Налаштування `.env`
Створіть файл `.env` у корені проекту на основі `.env.example`:
```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GEMINI_API_KEY=AIzaSyD-ва_ключ_від_gemini

# Модель генерації (Gemini Nano Banana 2.1)
IMAGE_MODEL=gemini-nano-banana-2.1

# Модель для описів та хештегів (Gemini 3.8 Flash)
CAPTION_MODEL=gemini-3.8-flash

# Безпечна пауза між запитами в секундах (для ліміту 2 RPM)
RATE_LIMIT_DELAY=32
```

### 5. Запуск тестів
```powershell
python -m pytest tests/
```

### 6. Запуск бота
```powershell
python -m src.main
```

## 📱 Сценарій взаємодії в Telegram

1. Натисніть `/start` у вашому боті.
2. Перейдіть у **«👩 Профіль AI-моделі»**:
   - Надішліть якісне фото **обличчя**.
   - Надішліть фото **фігури / тіла** (на повний зріст або по пояс).
3. Натисніть **«✨ Створити нове фото»**:
   - Надішліть фото **пози**.
   - Надішліть фото **одягу**.
   - Надішліть фото **заднього фону**.
   - Вкажіть додаткові побажання текстом або натисніть «⏩ Пропустити».
4. Натисніть **«🚀 Запустити генерацію»** або **«➕ Додати ще одне фото до сесії»** для пакетного запуску.
5. Бот поставить завдання в чергу, витримає необхідну паузу для дотримання ліміту Gemini API та надішле готове фото.
6. Натисніть **«📝 Згенерувати описи та хештеги»** — бот згенерує готовий текст для соцмереж англійською мовою.
